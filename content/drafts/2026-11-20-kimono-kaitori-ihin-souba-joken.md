遺品の着物は、状態と付属品がそろえば値が付くことがあります。ただし多くは数百円〜数千円で、すべてが売れるわけではありません。
洗う・仕立て直す・証紙を捨てる。この3つは、査定を受ける前にしないでください。

## 遺品の着物は売れる？現場で見る現実

「桐箪笥いっぱいの着物だから、高く売れるはず」。ご遺族からよく聞く言葉です。
気持ちはよく分かります。ただ、買取の現場では量よりも「状態」と「付属品」で値段が決まります。

私は古物・買取の現場に20年以上立ってきました。着物は、ひと箱ぶんを査定しても、値が付くのは数枚ということが珍しくありません。
一方で、捨てる寸前だった1枚に、思わぬ値が付いたこともあります。
だからこそ、捨てる前に基準を知っておくことが大切です。

## 着物の買取相場｜2026年時点の目安

次の表は、2026年時点の目安です。状態・産地・需要で大きく変わります。

| 種類 | 買取額の目安 |
|---|---|
| 小紋・一般的な紬 | 0円〜数千円 |
| 訪問着・付下げ（状態良好） | 数百円〜1万円前後 |
| 振袖（状態良好・仕立て済み） | 数千円〜数万円 |
| 有名産地の紬（証紙付き） | 数千円〜数万円 |
| 作家物（落款・証明書あり） | 数万円〜十数万円、まれにそれ以上 |
| 帯（名古屋帯・袋帯） | 数百円〜1万円前後 |
| 喪服・黒留袖 | 0円〜数千円 |
| 浴衣・ウール・化繊の着物 | 0円が多い |

あくまで目安です。実物を見ないと、金額は確定しません。

着物そのものの値段は、貴金属ほど日々は動きません。ただ、人気の産地や作家は需要で上下します。
金・プラチナ製の帯留めやかんざしが一緒に出たときは別です。貴金属は相場が日々動くため、査定日の価格で決まります。

## 値段が付く条件・付かない条件

### 値段が付きやすい5つの条件

- **状態**：シミ・黄ばみ・カビ・虫食いが少ない
- **付属品**：証紙、たとう紙、作家の証明書、仕立ての記録が残っている
- **年代**：昭和後期〜平成の仕立てで、傷みが少ない
- **ブランドや作家**：産地の証紙や、作家の落款がある
- **需要**：振袖、訪問着、有名産地の紬など、着る人や海外需要がある

### 値段が付きにくい条件

- カビ臭・汗じみ・広い範囲の黄変がある
- 虫食いや裂けがある
- ポリエステルなど化繊で、産地や作家の情報がない
- 身丈・裄（ゆき）が極端に小さい
- 喪服など、使う場面が限られる

とくに、カビのにおいは厳しい項目です。においが強いと、状態がよくても値が付かないことがあります。
一方、証紙が残っているだけで、評価が変わる着物もあります。
より広い基準は、[遺品の買取で何が売れる｜値段が付く物と付かない物の基準](/posts/ihin-kaitori-nani-ga-ureru/)も参考にしてください。

## 査定の前にやってはいけないこと

善意の行動が、値段を下げることがあります。現場で見た失敗です。

- **自分で洗う・クリーニングに出す**：色落ちや縮み、風合いの損傷につながります
- **アイロンをかける**：絹や金糸を傷めることがあります
- **ほどく・切る・仕立て直す**：反物の状態に戻せず、評価が下がります
- **証紙やたとう紙を捨てる**：産地や作家の裏付けがなくなります
- **防虫剤を足す・混ぜる**：種類の違う防虫剤を混ぜると、シミやにおいの原因になることがあります
- **天日干しをする**：日焼けや色あせの原因になります

あるご家庭では、シミが気になり、すべてをクリーニングに出されました。戻ってきた着物は、風合いが変わっていました。
また、証紙を「ただの紙」と思って処分した例もあります。証紙がないと、作家物と分かっても評価しにくくなります。

迷ったら、何もせず、箱やたとう紙ごと保管してください。

## 売る前の準備と、見積りで見る項目

### 段取りは4つ

1. 相続人の間で、売却や処分の方針を確認する
2. 箪笥や箱から出さず、たとう紙のまま1か所に集める
3. 風通しのよい場所に置く（干さずに、置くだけ）
4. 全体と、証紙の写真を撮っておく

相続や形見分けの扱いは、事情で変わります。判断に迷うときは、専門家に確認してください。

### 査定員が見る項目

- 生地の素材（絹・化繊など）
- 証紙、落款、作家の証明書
- 仕立て（縫い、裏地、紋の有無）
- シミ・黄変・カビ・虫食い
- 寸法（身丈・裄）
- においと保管状態

寸法は意外に重要です。現代は体格が大きくなり、裄が長い着物のほうが需要があります。

## 値段が付かない着物の処分方法

値が付かなくても、ごみにするしかないわけではありません。

| 方法 | ポイント |
|---|---|
| 自治体回収 | 可燃ごみか、古布の資源回収か、自治体で異なる |
| 古布・古着のリサイクル | 回収業者や拠点の受け入れ条件を確認する |
| 寄付 | 福祉団体などで可否が分かれる。事前に問い合わせる |
| リメイク | 帯をテーブルセンターやバッグに作り替える |
| 供養 | 思い入れの強い品は、寺社の受付可否を確認する |

自治体の出し方は、地域でルールが違います。たとえば横浜市の場合は、[遺品整理 横浜市｜粗大ごみのルールと搬入先、マンション注意点](/posts/ihin-seiri-yokohama-gomi-rule/)で確認できます。お住まいの自治体の窓口にも確認してください。

捨てるかどうか決めきれない着物は、「保留箱」に入れましょう。母の晴れ着など、気持ちの整理に時間がかかる品は、急がなくて大丈夫です。

## 整理と買取を同じ窓口で頼むと楽になること

着物は、数十枚にたとう紙、桐箪笥がセットで出ることが多い品です。
買取は買取店、回収は回収業者と分けると、日程の調整も仕分けも二度手間になります。

整理と買取を同じ窓口に頼むと、次の点が楽になります。

- 訪問は1回で、売る物と処分する物を同時に仕分けできる
- 値が付かなかった着物も、そのまま同じ作業で搬出できる
- 買取額を、整理費用から差し引ける
