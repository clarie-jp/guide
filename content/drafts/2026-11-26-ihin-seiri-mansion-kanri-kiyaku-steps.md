マンションの遺品整理は、作業日を決める前に管理規約と管理人への届け出を確認します。
決めることは「搬出できる時間」「エレベーターの養生」「届け出の期限」の3つです。
先にここを押さえると、日程の変更や近隣とのトラブルを防げます。

## まず確認するのは管理規約と使用細則

マンションでは、共用部分の使い方に独自のルールがあります。
遺品整理は、引っ越しと同じく大きな荷物を何度も運び出す作業です。そのため規約の対象になることが多いです。

### 手元に用意する書類と連絡先

次の3つを探してください。

- 管理規約（本体）
- 使用細則（引っ越し・工事・搬出入のルールが書かれたもの）
- 管理人室または管理会社の連絡先

親御さんの家で見つからないときは、管理人室に直接たずねるのが早いです。
分譲マンションなら、郵便物や総会の資料の中に入っていることもあります。

賃貸マンションの場合は、管理会社や大家さんが窓口です。
退去期限との兼ね合いは「[賃貸の遺品整理と退去の期限｜大家への連絡と原状回復の確認](/posts/ihin-seiri-chintai-taikyo-kigen/)」も参考にしてください。

### 規約で見る項目

読むのは全部でなくて構いません。次の表の項目だけ拾えば足ります。

| 項目 | 確認する内容 | よくある例 |
|---|---|---|
| 搬出入の時間 | 使える曜日と時間帯 | 平日と土曜の日中のみ |
| エレベーター | 予約の要否、養生の指定 | 引っ越し用の予約が必要 |
| 届け出 | 書式、期限、提出先 | 数日〜1週間前までに提出 |
| 車両 | トラックの停車場所 | 来客用駐車場を事前予約 |
| ごみ | 共用ごみ置き場の使用可否 | 引っ越しごみは使用不可 |
| 預り金・養生費 | 管理組合への支払いの有無 | 規約により異なる |

「規約に書いていない」場合も、運用ルールがあることがあります。
最終的には管理人か管理会社に電話で確認すると確実です。

## 搬出時間の決め方

### 時間帯と曜日の制限

搬出を認める時間は、規約や細則で決まっていることが多いです。
たとえば次のような制限があります。

- 日曜・祝日は搬出入不可
- 開始は9時または10時以降
- 終了は17時まで（2026年時点の目安）
- 昼の休憩時間は作業を控える

制限は管理組合ごとに違います。上の数字はあくまで一例です。

### 現場でよくある時間のずれ

現場でよくあるのは、作業日を先に決めてしまう失敗です。
朝9時開始の予定でいたら、細則では10時からだった、という場面があります。

1時間遅れると、午後の搬出が詰まります。
終了時刻に間に合わず、翌日に持ち越す例もあります。

作業日数の目安は、間取りと荷物量で変わります。
2026年時点の目安では、1K〜1LDKで半日〜1日、2LDK〜3LDKで1〜2日ほどです。
時間制限が厳しいマンションは、この目安より長くなることがあります。

### 日程を決める順番

1. 管理規約で使える曜日と時間を確認する
2. 管理人に、希望日の予約状況を聞く
3. 業者と日程を調整する
4. 届け出を出す

業者に連絡するのは、2の後でも遅くありません。
ただ、早めに相談しておくと、日程の候補を一緒に出せます。

## エレベーター養生の確認ポイント

### 養生とは何か

養生は、エレベーターの床や壁、扉まわりを保護材で覆うことです。
共用廊下やエントランスの床に敷くこともあります。

荷物の角が当たって壁に傷をつけると、修繕費の請求につながることがあります。
その負担は所有者や依頼者になる場合があります。養生は、そのための備えです。

### 事前に聞いておくこと

管理人には次の点を確認します。

- エレベーターを専用で使えるか、他の住民と共用か
- 養生は管理組合が用意するか、業者が行うか
- 管理人の立ち会いが必要か
- 養生をしてよい範囲（かご内、廊下、エントランスなど）
- 養生の設置と撤去に時間をかけてよい時間帯

養生の設置には、30分〜1時間ほどかかることがあります（2026年時点の目安）。
その時間を作業時間に含めて計画してください。

### 大きな家具が入らないとき

タンスやベッド、食器棚が、エレベーターのかごに入らないことがあります。
その場合は階段で運ぶか、分解して運びます。

高層階では、搬出に思ったより時間がかかります。
クレーンなどの特殊な方法は、管理組合の許可が別に必要です。

こうした条件は、図面だけでは分かりません。
訪問見積りで、実際のエレベーターの大きさと廊下の幅を見て判断します。

## 管理人への届け出の手順

### 届け出までの流れ

次の順番で進めると、抜けが出にくくなります。

1. 管理規約と使用細則を読む
2. 管理人または管理会社に電話し、届け出の窓口を確認する
3. 希望日の予約状況と、必要書類を聞く
4. 業者の見積りを受け、作業日を仮決めする
5. 届け出書を記入して提出する
6. 隣近所と上下階に、作業日を伝える
7. 作業の前日に、管理人へ最終確認をする

### 届け出書に書く内容

書式は管理組合ごとに違いますが、書く内容は似ています。

- 作業日と作業時間
- 部屋番号と、所有者または居住者の名前
- 作業会社の名前と連絡先
- 作業人数と車両の台数
- 搬出する荷物の種類
- 養生をする範囲

作業会社の情報は、見積りが決まらないと書けません。
提出期限から逆算して、業者を決める時期を考えてください。

### 所有者が亡くなっている場合

親御さんが亡くなったあとは、届け出の名義に迷うことがあります。
相続人の誰かが代理で出せるかどうかは、管理組合の運用によります。

名義変更や相続の手続きは、司法書士などの専門家に確認してください。
あわせて「[遺品整理はいつから｜四十九日と相続と退去期限で決める](/posts/ihin-seiri-itsukara-timing/)」で時期の考え方を確認しておくと、日程を決めやすくなります。

### 近隣への挨拶は届け出と別に

届け出を出しても、住民が作業を知っているとは限りません。
特に上下階と両隣には、日時と作業内容を一言伝えておくと安心です。

玄関ドアに小さな案内文を貼る方法もあります。
音が出る作業の時間帯も、あわせて書いておくと伝わります。

## 見積りで確認する項目とよくある失敗

### 訪問見積りで見る項目

マンションでは、部屋の中より共用部分が費用と段取りを左右します。
訪問見積りでは、次の項目を見ます。

| 見る項目 | 理由 |
|---|---|
| 階数とエレベーターの有無 | 搬出の手間と人数が変わる |
| かごの大きさと扉の幅 | 大型家具が通るか判断する |
| 廊下、階段、エントランスの形 | 養生の範囲と搬出経路を決める |
| トラックの停車位置 | 運ぶ距離と時間に影響する |
| 搬出の時間制限 | 作業日数に影響する |
| 共用ごみ置き場の使用可否 | 処分の方法を決める |

見積りを依頼するときは、管理規約のコピーを見せると話が早く進みます。
見積りの流れは「[遺品整理の見積もりは無料｜訪問査定の流れと追加料金の条件](/posts/ihin-seiri-mitsumori-muryo-flow/)」で詳しく紹介しています。

### よくある失敗5つ

- 作業日を先に決め、規約の時間制限で日程が崩れた
- 届け出に必要な業者情報が、提出期限に間に合わなかった
- 共用ごみ置き場に出し、管理人から注意を受けた
- エレベーターに入らない家具が、当日になって分かった
- 近隣へ伝えておらず、苦情が管理人に入った

どれも、作業前の確認で防げるものです。
業者を選ぶときは、規約の確認を一緒に進めてくれるかを見てください。
トラブルを防ぐ考え方は「[遺品整理のトラブル事例と防ぎ方｜クーリングオフも解説](/posts/ihin-seiri-trouble-prevention/)」にまとめています。

### 費用の見方

マンションの搬出条件が厳しいと、人数や作業日数が増えることがあります。
そのため、見積りは訪問で条件を見てから出す形が安心です。

クラリエの整理費用の目安は、2026年時点で次のとおりです。買取額を差し引く前の金額です。

| 間取り | 整理費用の目安 |
|---|---|
| 1K〜1LDK | 5万円〜 |
| 2LDK〜3LDK | 7万円〜 |
| 戸建て | 10万円〜 |

実際の金額は、荷物量と搬出条件で決まります。

## 次にやることと相談先

読み終えたら、次の順で動いてください。

1. 管理規約と使用細則を探す
2. 管理人に、搬出時間と届け出の窓口を聞く
3. エレベーターの大きさを測るか、写真を撮る
4. 見積りを取り、作業日を仮決めする
5. 届け出を出し、近隣に伝える

自分たちで進めるか、業者に任せるかは、荷物量と時間の余裕で決められます。
平日に動けない場合や、遠方に住んでいる場合は、任せる選択肢もあります。
立ち会えない場合は「[遺品整理を立ち会いなしで頼む手順｜鍵の受け渡しと写真報告](/posts/ihin-seiri-tachiai-nashi-flow/)」も確認してみてください。

- 訪問見積りで条件を確認し、作業後の追加請求はしません
- 買取と整理を一括で行い、買取額を整理費用から差し引けます
